# Lab 03 – Ataque a plataformas de aprendizaje digital

## Objetivo
Reconocer que Exploits utilizaron los hackers.

## Conceptos clave
- Exploits
- Violaciones de seguridad
- Información sensible

## Desarrollo
Detectar como obtuvieron acceso los hackers a la base de datos de usuarios en una plataforma eLearning.

## Evidencias
- Capturas almacenadas en labs/lab-03-elearning/evidencias/


## Aprendizajes clave
- Prácticas de seguridad
- Métodos de control de acceso

## Conclusión personal
Todas las organizaciones corren el riesgo de sufrir un ciberataque y, por lo tanto, deben tomar las medidas adecuadas para protegerse.
